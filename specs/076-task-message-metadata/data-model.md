# Data Model: 任务会话消息不含会话元信息

无持久化数据变更。约束作用于以下文字载体：

| 载体 | 书写者 | 约束 |
| --- | --- | --- |
| `session_create` 的 `prompt` | 调度模型 | 只装任务请求 |
| `session_send` 的 `text` | 调度模型 | 只表达任务本身、用户原话或要任务会话回答的问题 |
| `task_update` `add_message` 的文字 | 调度模型 | 与投递文字同口径 |

元信息清单（调度措辞不写）：

1. 模型路由与模型切换动作。
2. 上一轮失败原因，含模型服务拦截。
3. 工作区标识与工作目录路径。
4. 会话 id。

例外（照常写入）：

1. 用户原话，含原话提到的上述内容。
2. 任务需要的具体文件路径，例如调度工作区的报告与附件路径。

事实来源：

- 工作目录：宿主系统提示词。
- 模型切换：宿主 `[model changed: ...]` 提示。
- 失败原因：调度会话与用户之间流转。
