# 数据模型: 桥接会话默认预设

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-11-23

## 配置项 sessionPreset

新建桥接会话使用的预设标识，类型为字符串，随插件配置热重载。

| 状态 | profile 中的值 | 生效值 | 配置页显示 | 新建会话预设 |
| --- | --- | --- | --- | --- |
| 未保存过 | 无该键 | `sa-dispatch` | `SA-调度会话` | `sa-dispatch` |
| 已选预设 | 预设 id | 预设 id | 预设显示名 | 预设 id |
| 旧配置空值 | `''` | `''` | 跟随宿主默认 | 宿主默认 |
| 已选值不可用 | 预设 id | 预设 id | `<id> · 不可用` | 宿主默认，记录警告 |
| 名册不可读 | 预设 id 或缺省值 | 同左 | 预设 id 或「跟随宿主默认」 | 宿主默认，记录警告 |

## 规则

- 缺省值来自 `src/config.ts` 的 `Config` schema，`DEFAULT_CONFIG` 与之一致。
- `presetOf` 去掉首尾空白；结果为空串时按空值处理。
- 配置页菜单列出名册中未损坏的预设；旧配置的空值只出现在触发器文案，不出现在菜单。
- 用户保存任一预设后，配置文件写入该预设 id。
- 预设不可用或名册读取失败时，新建会话回退宿主默认，并写入一次警告日志。

## 状态迁移

| 起点 | 事件 | 终点 |
| --- | --- | --- |
| 未保存过 | 打开配置页 | 未保存过，显示默认预设 |
| 未保存过 | 选择预设并保存 | 已选预设 |
| 已选预设 | 改选其他预设并保存 | 已选预设 |
| 旧配置空值 | 选择预设并保存 | 已选预设 |
| 已选预设 | 预设行被停用 | 已选值不可用 |
| 已选预设 | 预设行恢复 | 已选预设 |
