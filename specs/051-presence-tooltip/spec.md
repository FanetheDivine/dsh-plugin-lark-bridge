## User Scenarios & Testing *(mandatory)*

### User Story 1 - 悬停立即看到状态与切换结果 (Priority: P1)

用户把指针移到侧栏页脚的在场状态按钮上，提示气泡立即出现，写明当前状态与点击后的状态，例如「在电脑旁 · 点击切换为离开」。

**Why this priority**: 用户需要在不等待浏览器延迟的情况下确认按钮含义，尤其在离开电脑前主动切换时。

**Independent Test**: 分别用两种在场状态悬停按钮，计时确认提示立即出现且文案与状态一致。

**Acceptance Scenarios**:

1. **Given** 状态为在电脑旁，**When** 指针进入按钮，**Then** 提示气泡立即出现「在电脑旁 · 点击切换为离开」。
2. **Given** 状态为离开，**When** 指针进入按钮，**Then** 提示气泡立即出现「离开 · 点击切换为在电脑旁」。
3. **Given** 提示已显示，**When** 指针离开按钮，**Then** 提示立即消失。
4. **Given** 最近一次切换失败，**When** 指针进入按钮，**Then** 提示立即显示「切换失败，点击重试」。
5. **Given** 按钮未获得焦点，**When** 用户用 Tab 键聚焦按钮，**Then** 提示立即出现，失焦后立即收起。

### User Story 2 - 提示不干扰切换并适应侧栏边界 (Priority: P2)

提示气泡显示在按钮上方，不被侧栏或窗口边缘裁切；用户点击按钮时切换照常发生，提示按悬停规则收起。

**Why this priority**: 提示是辅助信息，不能遮挡按钮或阻断既有切换交互。

**Independent Test**: 在展开与折叠侧栏、窗口左右两侧分别悬停与点击，确认气泡可见且切换正常。

**Acceptance Scenarios**:

1. **Given** 侧栏展开且按钮位于页脚，**When** 用户悬停按钮，**Then** 气泡在按钮上方完整可见。
2. **Given** 侧栏折叠为图标栏，**When** 用户悬停按钮，**Then** 气泡在按钮上方完整可见。
3. **Given** 提示已显示，**When** 用户点击按钮，**Then** 状态立即切换，且提示不残留为固定气泡。
4. **Given** 按钮上方空间不足，**When** 用户悬停按钮，**Then** 气泡自动换到可完整显示的一侧。

### Edge Cases

- 鼠标从按钮快速划过时，提示随指针离开立即收起。
- 提示显示期间状态被自动更新，下一次悬停显示最新状态的文案。
- 提示显示期间切换失败，提示在可见时更新为失败文案。
- 触屏设备没有悬停，点击仍只执行切换。
- 页面切换到另一种语言后，提示文案跟随当前语言。
- 侧栏折叠与展开切换时，提示不残留。
- 键盘焦点在按钮上时切换侧栏宽度，提示位置随按钮更新。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 在场状态按钮的提示 MUST 由页面内提示气泡呈现，替代浏览器原生标题提示。
- **FR-002**: 指针进入按钮时，提示气泡 MUST 立即出现，不设置人为延迟。
- **FR-003**: 提示文案 MUST 沿用按钮现有的「当前状态 · 点击后的状态」文案，失败时显示重试文案。
- **FR-004**: 指针离开按钮时，提示气泡 MUST 立即收起。
- **FR-005**: 提示气泡 MUST 优先显示在按钮上方；上方空间不足时 MUST 自动换到可完整显示的一侧，并避开窗口边缘与侧栏裁切。
- **FR-006**: 点击按钮 MUST 维持现有行为：立即切换状态，不要求确认。
- **FR-007**: 提示 MUST 为读屏保留按钮的无障碍名称。
- **FR-008**: 提示文案 MUST 提供中文与英文。
- **FR-009**: 触屏点击 MUST 只执行切换，不固定展示提示。
- **FR-010**: 提示显示期间状态变化 MAY 更新可见文案；下一次展示 MUST 反映最新状态。
- **FR-011**: 键盘聚焦按钮时，提示 MUST 立即出现；失焦时 MUST 立即收起。
- **FR-012**: 提示组件 MUST 采用 shadcn/ui 的 Tooltip 封装，底层使用 Radix UI。

### Key Entities

- **在场状态**：`local` 表示在电脑旁，`remote` 表示离开。
- **提示气泡**：悬停按钮时出现的页面内浮层，含当前状态与点击效果文案。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 指针进入或键盘聚焦按钮到提示气泡可见的间隔不超过 100 毫秒。
- **SC-002**: 两种状态与失败态下，提示文案与按钮状态一致，中英文各验证一次。
- **SC-003**: 展开侧栏、折叠侧栏与上方空间不足三种情况下，气泡均完整可见。
- **SC-004**: 点击按钮后状态在 200 毫秒内变化，提示不固定残留。

## Assumptions

- 提示沿用 shadcn 组件体系与映射到宿主令牌的语义色，不引入新的视觉体系。
- 提示只作用于页脚在场状态按钮，其他按钮的提示不在本次范围。
