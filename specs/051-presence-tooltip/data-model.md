# Data Model: 在场状态按钮即时 tooltip

## 界面状态

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `presence` | `'local' \| 'remote'` | 当前全局在场状态 |
| `failed` | `boolean` | 最近一次切换是否失败 |
| `open` | `boolean` | Radix Tooltip 内部展开状态 |

## 派生文案

| 条件 | 提示文案 |
| --- | --- |
| `failed` | 切换失败，点击重试 |
| `presence === 'local'` | 在电脑旁 · 点击切换为离开 |
| `presence === 'remote'` | 离开 · 点击切换为在电脑旁 |

英文文案由 `src/client/locales.ts` 提供。

## 状态转换

| 起点 | 事件 | 终点 |
| --- | --- | --- |
| 关闭 | 指针进入按钮 | 打开 |
| 关闭 | 键盘聚焦按钮 | 打开 |
| 打开 | 指针离开按钮 | 关闭 |
| 打开 | 失焦 | 关闭 |
| 打开 | 点击按钮 | 状态切换；提示按悬停/焦点状态继续显示 |
| 任意 | 组件卸载 | 提示移除 |

## 持久化

无。状态仍由现有 `PresenceController` 管理，本次不改变数据形态。
