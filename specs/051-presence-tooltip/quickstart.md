# Quickstart: 在场状态按钮即时 tooltip

## 前置

- Node.js >= 24.9.0
- pnpm 11.7.0
- 已安装依赖：`pnpm install`

## 自动验证

```bash
pnpm test:code -- tests/presence-client.test.ts
pnpm format
pnpm check
```

预期：

- 按钮 HTML 不含 `title` 属性。
- 指针移入或聚焦按钮后，`[role="tooltip"]` 在 100 ms 内可见并显示当前状态文案。
- 指针移出或失焦后提示移除。
- 构建产物包含 tooltip 样式，`pnpm check` 全绿。

## 实机验证

1. 在 DSH 中启用「飞书任务与调度会话」行，确认侧栏页脚显示在场状态按钮。
2. 悬停按钮，确认提示立即出现，文案为「在电脑旁 · 点击切换为离开」。
3. 点击按钮，确认状态切换为离开，下一次悬停显示「离开 · 点击切换为在电脑旁」。
4. 用 Tab 键聚焦按钮，确认提示立即出现；移开焦点后收起。
5. 折叠侧栏，重复悬停，确认气泡在按钮上方完整可见。
6. 缩小窗口或滚动到窗口底部，确认气泡自动换到可完整显示的一侧。
7. 切换界面语言为英文，确认提示为英文文案。
