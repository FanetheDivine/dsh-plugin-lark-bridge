# 研究：迁移模板热更新与前端链接规则

**日期**：2026-11-20 | **规格**：[spec.md](./spec.md) | **计划**：[plan.md](./plan.md)

## R1 迁移范围

**决策**：按文件迁移模板 `fe93cd0` 与 `197480e` 的可移植内容：实机 skill 五个文件、`docs/development.md`、`CHANGELOG.md`。

**依据**：本项目对应 skill 与模板 `197480e` 的版本逐字一致；`docs/development.md` 缺少「前端 UI 链接」小节；CHANGELOG 缺少两条记录。模板规格目录按 D-001 不迁移。

**备选**：复制模板规格目录。会使本项目出现重复编号与重复维护，未采用。

## R2 链接安装

**决策**：搭建脚本用 `dsh plugin --profile <profile> add <repo>` 安装被测插件，profile 记录 `link:<仓库绝对路径>`，`node_modules/<插件>` 指向仓库。

**依据**：模板 `fe93cd0` 在相同宿主版本 `0.2.2-rc.3` 上验证：HMR 只替换链接包的目标文件；打包安装的副本不随仓库重建变化。本项目宿主版本与模板一致。

**备选**：保留 tgz 安装并在重建后同步产物。需要额外触发重载，未采用。

## R3 HMR 启用

**决策**：profile 补丁写入 `- id: hmr` 与 `config.root: ["<repo>/dist"]`。新建补丁整块写入；复用补丁缺该条目时先移除 `[]` 占位行再追加。

**依据**：模板在同一宿主版本验证了 `dsh-hmr` 的替换行为；`dsh-base` 在 launcher 提供 `profileContext` 时启用 `hmr` 条目。`[]` 后直接追加列表项会产生非法 YAML，模板研究中已复现。

**风险**：`ignored` 默认含 `**/.*`，仓库位于点目录时监听被跳过；写入排错表。

## R4 前端自动更新

**决策**：不增加前端同步逻辑，skill 说明前端产物由宿主自动替换。

**依据**：模板研究记录 `dsh-client-hmr` 每 500 毫秒轮询客户端产物并推送重建帧；本项目前端产物同为 `dist/client.js`。

## R5 装载用例

**决策**：A1 保持「版本一致 + `dist/index.mjs` 哈希一致」，只把提示文案从「已安装」改为「加载」。

**依据**：链接安装下 `node_modules/<插件>` 指向仓库，哈希比较仍能发现加载产物与仓库不一致。

## R6 每轮清理

**决策**：skill 收尾删除 profile；截图与结果先写入报告。

**依据**：规格 D-003 与模板 020 的清理规则；旧 profile 不迁移。

## R7 热更新验证段

**决策**：模板新增验证段中的 `src/demo-tool.ts` 改为 `src/tools.ts` 的 `lark_notify` 说明文本；`ECHO_CASE:hot` 与工具卡片改为任意消息与 `requests.jsonl` 的 `tools` 字段。

**依据**：规格 D-002。本项目没有 demo 工具；`mock-provider.mjs` 把每次模型请求写入 `requests.jsonl`，请求的 `tools` 含已注册工具及其说明，可直接断言。其余 demo 用例保持模板原文。

**风险**：`setup-env.sh` 仍写入模板的 `prefix: rdt`，本插件会以未知配置键拒绝加载，插件无法注册 `lark_notify`。该适配超出本次范围，记录在计划风险与规格审查记录中。

## R8 验证方式

**决策**：本次只运行质量门禁、脚本语法检查与模板 diff 核对。

**依据**：规格 D-003 明确不做完整实机回归。实机验证需要先修正 profile 配置并适配 demo 用例。

**备选**：临时修正 profile 后手工验证 HMR。会产生未提交的临时改动，且 demo 用例仍失败，未采用。

## R9 前端链接规则

**决策**：`docs/development.md` 在「前端构建」后新增小节，要求 `a` 标签的 `href` 使用含协议与主机的完整 URL，示例指向本项目仓库。

**依据**：模板 `197480e`；Desktop 用应用内地址加载前端页面，相对链接会指向应用地址。本项目现有唯一 `href` 取自 `lark-cli` 返回的 `verification_url`，已是完整地址，不改代码。
