# Quickstart: 调度会话统一管理任务会话

## 前提

- 插件构建产物已装入本机 DSH，`SA-调度会话` 是桥接会话的预设。
- 调度工作区是 git 仓库，至少登记一个工作区笔记。

## 自动验证

```sh
pnpm format && pnpm check
pnpm full-check
```

## 真机场景

| # | 操作 | 预期 |
| --- | --- | --- |
| 1 | 调度会话 `session_create` 新建会话 | 会话使用「任务会话预设」；`message-task-status.json` 出现对应任务 |
| 2 | 普通会话调用 `send_report` | 返回未被管理错误，调度会话无消息 |
| 3 | 调度会话 `session_manage` 一个普通会话 | 出现任务；该会话可成功上报 |
| 4 | 被管理会话完成一轮回复 | 调度会话收到 `origin="turn_end"` 的 `progress` 上报 |
| 5 | 被管理会话提问等待中，切为离开 | 提问立即返回离开错误，轮次继续；下一次请求含 S |
| 6 | 宿主重启前已有等待中的提问，重启后切为离开 | 同 5 |
| 7 | 离开期间被管理会话再次提问 | 立即返回离开错误 |
| 8 | 在 Web GUI 查看上报 | `send_report` 显示为专用卡片 |
| 9 | 在界面归档被管理会话 | 任务归档，`endReason` 为 `session_archived` |
| 9a | 用户确认任务完成后结束任务 | 任务归档，会话保持未归档 |
| 10 | 调度会话 `session_unmanage` | 任务归档，会话保留 |
| 11 | 离开期间触发权限审批 | 审批弹窗保持等待 |
| 12 | 离开期间被管理会话需要用户决定 | 会话用 `question` 上报提问，调度会话经飞书转达 |
