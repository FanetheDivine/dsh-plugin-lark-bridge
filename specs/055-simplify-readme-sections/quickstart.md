# Quickstart: 精简 README 最后两节

## 验证步骤

1. 检查 `README.md` 的「关于调度会话」与「在场状态」两节：
   - 「关于调度会话」包含默认预设说明、新建或接管任务会话、配置页设置任务模型与预设三项要点，不含 `session_create`、`task_type` 等内部标识。
   - 「在场状态」包含在电脑旁与离开时的飞书交互说明，以及侧栏图标切换、网页/飞书输入自动切换、定时切换（支持跳过周末和节假日）三项要点，不含控件操作与缓存回退细节。
2. 运行质量门禁：

   ```sh
   pnpm format && pnpm check
   ```

   确认全部检查与测试通过。
