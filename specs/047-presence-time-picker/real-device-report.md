# 实机验证报告：自动切换时间的配置行与时间选择浮窗

**日期**：2026-11-25
**环境**：全局 `dsh` 0.2.2-rc.5，隔离 profile `rdt-047`（端口 3210），插件以 link 方式安装本 worktree，mock 模型。用户正在使用的 GUI 不受影响。
**方法**：Playwright 驱动无头 Chrome 操作 GUI；profile 的 `cordis.patch.yml` 预置三条时间条目：`09:15`（启用、跳过周末）、`18:40`（停用）、`21:05`（离开分区）。

## 过程中发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| 只引入 `tailwindcss/utilities` 时，依赖 `--spacing` 的间距类与 `calc()` 尺寸不生成，列高度失控到 1307px | 补引入 `tailwindcss/theme`，保留 `utilities`，仍然不引 preflight |
| 浮窗 `z-50` 低于宿主 Modal 的 `z-index: 1000`，被遮罩挡住且点不到 | 浮窗层级改为 `z-[1100]` |
| 卡片底色用 `bg-layer-1` 与页面白底同色，看不出边界 | 改用 `bg-layer-2` |

## 未覆盖项

- 深色主题由宿主设置页切换，本轮未截图核对；令牌映射与浅色共用同一份 `--dsw-*`。
- 触屏与键盘逐项操作未在实机逐条验证，键盘行为由移植件的实现与单元测试覆盖。
