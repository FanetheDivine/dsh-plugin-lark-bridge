## 过程中发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| 浏览器产物内联的第三方组件读取 `process.env.NODE_ENV`，浏览器里抛错导致整个前端产物不加载（无在场按钮、无配置页） | 客户端构建加 `define: { 'process.env.NODE_ENV': '"production"' }` |
| 时间输入框失焦前点「确认」无响应：表盘在输入框聚焦时自动展开，外部点击被弹层吃掉 | 改为聚焦不展开表盘，用输入框右侧的时钟按钮显式打开 |
| 输入小时时给出不带前导零的值（`9:15`），校验判为非法导致无法保存 | 输入变化时统一补零为 `HH:mm` |
| 配置页在没有任何闹钟时也会显示节假日数据提示 | 仅在存在启用且跳过节假日的条目时提示；行启用时提前取一次数据，避免刚启动就显示 `missing` |

## 未覆盖项

- 时钟平移通过预加载脚本完成，宿主其余时间相关行为（会话时间戳等）在同一进程内一并平移；生产代码不包含该逻辑。
- 手动切换与自动切换同分钟竞争的严格用例由 `tests/presence-schedule.test.ts` 覆盖，实机只验证了切换后保持。
