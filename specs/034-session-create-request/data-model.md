# 数据模型: 修复桥接会话创建请求

## 创建请求

| 字段 | 现状 | 修复后 | 说明 |
| --- | --- | --- | --- |
| `workspaceId` | 必填 | 必填 | 已注册工作区标识，宿主据此确定会话目录并挂载 |
| `cwd` | 必填 | 移除 | 与 `workspaceId` 互斥，宿主拒绝同时出现 |
| `sessionId` | 必填（本地随机） | 移除 | 宿主只在复用时读取，新建时自行铸造 |
| `agentPreset` | 可选 | 可选 | 预设可用时传入，否则省略 |

## 创建结果

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `sessionId` | string | 宿主返回的会话标识，插件以其为准 |
| `agentPreset` | string? | 宿主记录的预设，插件不依赖该字段 |

## 桥接状态文件

字段不变：`sessionId`、`workspaceRoot`、`title`、`seen`、`updatedAt`。

| 时序 | 写入 |
| --- | --- |
| 收到消息 | `seen` 增加消息标识 |
| 新建成功 | `sessionId`、`workspaceRoot`、`title` 覆盖 |
| 新建失败 | 不写入，保留旧值 |

## 会话

| 属性 | 来源 | 说明 |
| --- | --- | --- |
| 目录 | 工作区路径 | 宿主以 `workspace.path` 创建 |
| 标题 | 固定标题 | 创建后追加 `session/title` |
| 预设 | 创建请求或宿主默认 | 预设不可用时省略 |
| 模型 | 配置与校验 | 创建后写入，不改变宿主默认 |
| 置顶 | 插件 | 创建成功后加入置顶集合 |
