# Contract: 配置页的模型与预设行

## 布局

配置页自上而下：

1. 鉴权面板。
2. 工作区行。
3. 模型行。
4. 预设行。
5. 保存栏。

## 模型行

- 使用官方 `ModelSelect`，包含模型与推理等级两级菜单。
- 触发器、当前值与选项把 provider 显示在模型名称前。
- 推理等级只列出所选模型支持的等级；模型没有推理元数据时不显示该控制。
- 选择把 provider、model、effort 写入配置草稿的 `sessionProvider`、`sessionModel`、`sessionEffort`。
- 已存模型不在目录中时显示未选择状态，配置值保留。
- 目录加载中、加载失败沿用官方组件状态。

## 预设行

- 右侧 `select` 触发器，浮窗使用宿主 `Menu`，通过 portal 渲染。
- 首项「跟随宿主默认」，写入空值；其后按宿主名册顺序列出可用预设。
- 未选择时触发器显示「跟随宿主默认」；已选可用预设显示名称，名称为空时显示标识。
- 已选预设不可用时显示标识并追加「不可用」，菜单中该值以禁用项补足。
- 名册加载中、加载失败或宿主无预设能力时触发器禁用。
- 加载失败时显示失败文案与重试按钮，已保存值保留。
- 支持方向键移动、回车选择、Esc 关闭并返回触发器焦点。

## 行为

- 模型与预设选择只修改配置草稿，不直接保存。
- 保存后经现有热更新流程用于之后新建的会话。
- 放弃草稿恢复已保存值。
- 配置页只读、保存失败与保存中时两个控件禁用。
- 关闭会话创建能力时两个控件仍可编辑；配置保留。
- 现有鉴权面板、工作区行与保存栏行为不变。
