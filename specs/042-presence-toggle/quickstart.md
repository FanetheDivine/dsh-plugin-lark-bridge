# Quickstart: 侧栏在场状态按钮

## 前提

- 在 worktree 根目录执行 `pnpm install`。
- 实机验证需要已完成飞书授权的 DSH 与 `SA-调度会话` 桥接会话。

## 自动检查

```sh
pnpm format && pnpm check
pnpm build
```

## 实机场景

用 `real-device-test` skill 把本 worktree 装进真实 DSH 后逐项验证：

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 初始 | 重启 DSH，查看侧栏页脚 | 重启按钮之后出现绿色显示器 |
| 手动切换 | 单击按钮 | 立即变为灰色手机；悬停提示「离开 · 点击切换为在电脑旁」 |
| 多页同步 | 两个标签页打开 GUI，在其一切换 | 另一页 3 秒内同步 |
| GUI 输入 | 状态为离开时在任一会话发送文本 | 3 秒内变为在电脑旁 |
| 飞书输入 | 在飞书私聊发送消息 | 3 秒内变为离开；调度会话经 `lark_notify` 回复 |
| 开关关闭 | 关闭 GUI 输入开关后在 GUI 发送文本 | 状态不变 |
| 提醒按属性 | 切换后唤醒调度会话 | 会话中出现一条带 `presence` 属性的提醒；状态未变时不再插入 |
| 行停用 | 在 Plugins 页停用「飞书任务与调度会话」 | 3 秒内按钮消失；重新启用后出现 |
| 折叠侧栏 | 折叠侧栏 | 按钮在纵列中可见、可点击 |
| 工作会话远程 | 状态为离开时唤醒工作会话并让它提问 | 经 `send_report` 提问 |
| 工作会话本机 | 状态为在电脑旁时让工作会话完成任务 | 正文对话；完成经 `send_report` 上报，无「用户在电脑前」首行 |
| 其他预设 | 在默认预设会话中对话 | 无在场提醒 |
