# 数据模型: 设置界面 UI 优化

**Feature**: `028-plugin-ui-polish`

界面只有派生视图状态，没有新增持久化字段。配置仍只有 `workspaceRoot`。

## 工作区选项

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| `id` | `WorkspaceListItem.workspaceId` | `Menu` 的 `selectedId` |
| `title` | `WorkspaceListItem.title` | 显示名 |
| `path` | `normalizeWorkspacePath(WorkspaceListItem.path)` | 归一化路径，作为选中值 |

约束：

- 选项集合等于宿主注册列表，按列表顺序展示。
- 选中值为空或不在列表内时，触发控件显示占位文案「请选择工作区」。
- 列表为空时触发控件显示「暂无已注册工作区」并禁用。

## 浮层状态

| 状态 | 取值 | 转换 |
| --- | --- | --- |
| `open` | 布尔 | 点击触发控件切换；选中、Esc、点击外部、失焦到 iframe 时关闭 |

## 复制状态

| 状态 | 取值 | 转换 |
| --- | --- | --- |
| `copied` | 布尔 | 写入剪贴板成功后为真，约 1 秒后自动复位；写入失败保持假 |

每条命令各自持有一个复制状态，互不影响。

## 连接项展示

| 字段 | 取值 |
| --- | --- |
| 名称 | lark-cli / 机器人身份 / 用户身份 |
| 状态 | `已连接`、`未连接`、`检测中…` |
| 检测按钮 | 文案保留全称，紧邻状态文字，`busy` 时禁用 |
| 命令 | 固定命令原文，右侧带复制按钮 |

## 失效签名

沿用 `getAuthOverlaySignature`：连接状态与工作区有效性共同决定弹窗是否重开，本次不改。
