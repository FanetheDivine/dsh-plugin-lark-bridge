# dsh-plugin-lark-bridge

[![npm](https://img.shields.io/npm/v/dsh-plugin-lark-bridge?logo=npm&label=npm)](https://www.npmjs.com/package/dsh-plugin-lark-bridge)

借助 lark-cli，让 DSH 以飞书机器人身份和你私聊对话。

## 使用

1. 安装或升级 lark-cli：

   ```sh
   npm install -g @larksuite/cli@latest
   ```

2. 配置机器人身份：

   ```sh
   lark-cli config init
   ```

3. 登录授权用户：

   ```sh
   lark-cli auth login --scope auth:user.id:read
   ```

4. 在「用飞书和DSH对话」的配置页选择工作区。
5. 在飞书私聊机器人，与 DSH 对话。

## 关于两个预设

本插件提供 `SA-调度会话` 与 `SA-工作会话` 两个预设，用飞书远程派发任务。

- 在「插件」页保持这两行启用。
- 在「用飞书和DSH对话」的配置页，把「预设」设为 `SA-调度会话`。
- 「用飞书和DSH对话」配置页的「模型」是 `SA-调度会话` 自己的模型。
- 「飞书任务与调度会话」配置页的「工作会话模型」是 `SA-调度会话` 新建 `SA-工作会话` 时使用的模型与推理等级，未选择时使用宿主默认。

## 在场状态

两个预设按「你是否在电脑旁」选择交流渠道：在电脑旁时直接在会话正文对话，离开时经飞书联系你。

- 侧栏底部的图标显示当前状态：绿色显示器表示在电脑旁，灰色手机表示离开。
- 单击图标切换状态。离开电脑前切换，后续的回复与上报就会发到飞书。
- 每次启动 DSH 时状态为在电脑旁。
- 「飞书任务与调度会话」行的配置页有两个开关，默认开启：
  - 网页输入时切换为在电脑旁：在任一会话的网页中发消息，状态变为在电脑旁。
  - 收到飞书消息时切换为离开：给机器人发飞书私聊，状态变为离开。
- 同一配置页可添加「自动切换在电脑旁的时间」与「自动切换离开的时间」，每条时间单独设置是否跳过周末、是否跳过节假日。
- 到点只切换一次；手动切换后保持到下一个时间点。
- 中国法定节假日与调休数据在使用时联网获取并缓存，获取失败时使用上次缓存，没有缓存时只按周末跳过。
- 停用「飞书任务与调度会话」行时，图标随之隐藏，自动切换也不执行。
